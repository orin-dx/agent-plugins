## [1.0.0] - 2026-08-27

### Added
- Initial release. Component specification plugin: turns UI/design intent into unambiguous, testable component specs — props, variants, per-state observable behavior, and accessibility criteria as testable propositions, gated before planning. One skill (`component`), three subagents (`drafter`, `auditor`, `exit-gate`). Reuses `spec@1` and `verdict@1` — no new schema introduced. Added as the tenth plugin in the Wisp-branded ecosystem, alongside `scribe` in the Design category. See `docs/adr/007-wisp-persona-naming.md`.
